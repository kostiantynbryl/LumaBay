# Luma Bay: Match & Restore

Portrait mobile Match-3 restoration game for Android, developed under **Norvexa Games**.

## Current release target

**0.1.1 Alpha** — a premium visual and gameplay update built on the tested 0.1.0 vertical slice:

- 30 deterministic and rebalanced Match-3 levels;
- 8×8 board, cascades, automatic reshuffle and four special-piece types;
- collection and fog-clearing goals;
- crate, ice and net obstacles introduced progressively;
- five usable nautical boosters;
- level progression, stars, coins and versioned local saves;
- lighthouse restoration meta loop and short story progression;
- Russian and English interface and tutorials;
- ornate blue-and-gold maritime UI with pearls, glows and motion;
- illustrated sunset lighthouse background generated by the project;
- procedural visual and audio content, so no unlicensed third-party game assets are included;
- Android portrait safe-area handling and a generated application icon.

## Engine

- Unity **6000.3.18f1 / Unity 6.3 LTS**
- C#
- uGUI
- Android 8.0+
- ARM64 / IL2CPP
- package: `com.norvexa.lumabay`

Unity 6.3 LTS is the production baseline. Open the repository folder in Unity Hub. On the first script reload, the editor bootstrap creates `Assets/LumaBay/Scenes/LumaBayMain.unity` when needed, configures Android settings, generates the application icon and adds the scene to Build Settings.

## Run locally

1. Install Unity 6000.3.18f1 with Android Build Support, SDK, NDK and OpenJDK.
2. Clone the repository and switch to `develop/0.1.1-alpha`.
3. Open the repository root in Unity Hub.
4. Wait for package import, generated metadata and script compilation.
5. Open `Assets/LumaBay/Scenes/LumaBayMain.unity` if it is not already open.
6. Press Play.

The bootstrap can be run manually from **Luma Bay → Setup Project**.

## Android control build

Use **Luma Bay → Build Android Alpha** or run:

```powershell
Unity.exe -batchmode -quit -projectPath . -executeMethod LumaBay.Editor.LumaBayBuildScript.BuildAndroid
```

Output:

```text
Builds/Android/LumaBay-0.1.1-alpha.apk
```

The 0.1.1 control APK is a non-development ARM64 IL2CPP build with medium managed-code stripping. It uses debug signing for internal testing and is not yet a Google Play release artifact.

## Validation

Run the repository checks without a Unity license:

```text
python tools/validate_project.py
```

Unity EditMode tests cover board generation, match resolution and obstacle placement. The optional GitHub Actions workflows are manual to avoid unnecessary Actions usage.
